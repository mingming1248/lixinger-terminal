# 理杏仁终端 · Lixinger Terminal

一个油猴（Tampermonkey）脚本，把 [理杏仁](https://www.lixinger.com) 改造成金融终端式布局：左侧树形多级菜单 + 右侧完整页面，告别顶部层层展开的多级子菜单。

> **非官方项目**：本项目与理杏仁官方无关，仅为个人使用的浏览器端界面增强，不修改、不额外请求任何服务端数据。

## 效果

- 原站：14 个顶部一级菜单、80+ 二级页面，靠顶部导航层层点开，三级菜单要悬停展开，来回切换很麻烦
- 装后：左侧固定树形菜单（14 大模块 · 155+ 页面），默认只展开当前模块，点菜单直达页面；侧边栏顶部内嵌理杏仁官方 logo，与顶栏等高连成一体，整体呈现 Vue 后台管理式布局

## 功能特性

| 功能 | 说明 |
|------|------|
| 左侧树形多级菜单 | 14 大模块 · 155+ 页面，三级结构，默认仅展开当前所在模块 |
| 同模块 SPA 无刷新跳转 | 模块内切换页面不整页刷新（与原站行为一致），跨模块保持原站跳转 |
| 菜单即时搜索 | 按 <kbd>/</kbd> 聚焦搜索框，输入关键词过滤全菜单，唯一结果回车直达 |
| 官方 logo 入驻侧边栏 | 从页面实时克隆理杏仁官方 logo，顶栏原 logo 自动隐藏，避免重复 |
| 一体化顶带 | 侧边栏品牌区与顶栏高度同步、底边线连通，终端栏看起来就是页面原生结构 |
| 页脚对齐 | 底部网站链接区整体右移，与内容区左缘对齐，右侧呈现一个完整页面 |
| 扩大图表区 | 内容区顶部的面包屑与二级 tab 菜单自动隐藏，图表/表格直接顶到页面上方 |
| 刷新保持 | 侧边栏状态防重置：SPA 框架重写 body 类、移除侧边栏节点均自动恢复 |
| 一键开关 | 点侧边栏顶部「‹」收起即完全还原原站，点左侧「终端」按钮随时恢复 |
| 深色模式 | 自动跟随理杏仁的 Bootstrap 5 深色主题 |

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. Tampermonkey 图标 → 「添加新脚本」→ 全选删除，粘贴 [`lixinger-terminal.user.js`](lixinger-terminal.user.js) 全部内容 → `Ctrl+S` 保存
3. 打开 [www.lixinger.com](https://www.lixinger.com)，左侧出现「理杏仁 | 终端」侧边栏即成功

**注意**：新版 Chrome（Manifest V3）需要在 `chrome://extensions` 打开右上角「开发者模式」开关，Tampermonkey 才能执行用户脚本。

## 使用

- <kbd>/</kbd> 聚焦菜单搜索，<kbd>Esc</kbd> 清空退出，唯一匹配时 <kbd>Enter</kbd> 直达
- 侧边栏顶部 <kbd>‹</kbd> 按钮收起侧边栏（恢复原站）；收起后左上角「终端」按钮随时唤回
- 模块展开状态会记住：手动展开过的模块下次保持，当前浏览的模块始终自动展开
- 想保留原站内容区顶部的面包屑/二级菜单：把脚本头部 `HIDE_TOP_MENUS` 改为 `false`

## 安全与合规

- **零额外请求**：脚本只做前端 DOM/CSS 层面的界面重组，不发起任何额外网络请求，页面加载次数、数据查询次数、对服务器的访问次数与原站完全一致
- **不碰数据接口**：不抓取、不缓存、不转发任何数据，所有页面跳转走的都是理杏仁原生的路由
- **可随时完全还原**：收起侧边栏即恢复原站全部外观

## 常见问题

**刷新后侧边栏消失了？**
v0.4.0+ 已修复（站点框架重写 body class 导致）。若仍出现，确认脚本版本 ≥ 0.4.0，并检查 Chrome「开发者模式」开关是否打开。

**正文和顶栏 logo 不对齐？**
v0.4.1+ 已修复（双重缩进问题）。若个别页面仍有错位，欢迎提 Issue 并附上页面路径。

**会封号吗？**
脚本行为等同于正常浏览页面，不模拟请求、不改变任何与服务器的交互，理论上无风险。但请自行评估并遵守理杏仁用户协议。

**菜单数据过时了怎么办？**
脚本内置「自愈」机制：每次访问页面时从当前页面包屑自动同步菜单结构，理杏仁增删页面无需更新脚本。
